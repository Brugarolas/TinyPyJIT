# TinyPy

TinyPy is a tiny Python 3 engine with a register-based interpreter, a generational garbage collector, and an optimizing JIT made with SLJIT. It's written in C11.
It has a competitive performance, normally on par or exceeding CPython 3.15 performance, with a much lower impact on memory and CPU usage.
Developers are able to write Python bindings via C-API or pybind11 compatible interfaces.

## Supported Platforms

TinyPy should work on any platform with a C11 compiler.
These platforms are officially tested.

+ Windows x86_64
+ Linux x86_64
+ macOS x86_64 / ARM64
+ Android x86_64 / ARM64
+ iOS ARM64

## Features

| Name            | Example                         | Supported |
| --------------- | ------------------------------- | --------- |
| If Else         | `if..else..elif`                | ✅       |
| Loop            | `for/while/break/continue`      | ✅       |
| Function        | `def f(x,*args,y=1):`           | ✅       |
| Subclass        | `class A(B):`                   | ✅       |
| List            | `[1, 2, 'a']`                   | ✅       |
| ListComp        | `[i for i in range(5)]`         | ✅       |
| Slice           | `a[1:2], a[:2], a[1:]`          | ✅       |
| Tuple           | `(1, 2, 'a')`                   | ✅       |
| Dict            | `{'a': 1, 'b': 2}`              | ✅       |
| F-String        | `f'value is {x}'`               | ✅       |
| Unpacking       | `a, b = 1, 2`                   | ✅       |
| Star Unpacking  | `a, *b = [1, 2, 3]`             | ✅       |
| Exception       | `raise/try..except..`           | ✅       |
| Dynamic Code    | `eval()/exec()`                 | ✅       |
| Reflection      | `hasattr()/getattr()/setattr()` | ✅       |
| Import          | `import/from..import`           | ✅       |
| Context Block   | `with <expr> as <id>:`          | ✅       |
| Type Annotation | `def f(a:int, b:float=1)`       | ✅       |
| Generator       | `yield i`                       | ✅       |
| Decorator       | `@cache`                        | ✅       |
| Match Case      | `match code: case 200:`         | ✅       |
